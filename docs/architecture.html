Architecture

Request / Data Flow

1

User adjusts a filter

Time Period, Warehouse, Category, or Order Status changes in FilterBar.vue, updating shared reactive state in the useFilters composable.

2

View requests data

A view (e.g. Dashboard.vue) reads the current filters and calls a method on client/src/api.js, the centralized Axios client.

3

HTTP request to the API

Axios sends a GET request with query params (e.g. ?warehouse=west&category=electronics) to http://localhost:8001/api/....

4

FastAPI filters in-memory data

main.py applies apply_filters() / filter_by_month() over the Python lists already loaded by mock_data.py — no database query, just list comprehensions.

5

Pydantic validates the response

Results are serialized through response_model-typed Pydantic models before being returned as JSON.

6

Vue derives and renders

The response is stored in a raw ref (e.g. allOrders); computed properties derive chart and table data, and the template re-renders reactively.
